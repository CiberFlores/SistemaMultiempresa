# Arca Nova

Aplica este flujo siempre que diseñes, modifiques o revises una interfaz del proyecto.

- Consulta `impeccable` para composición, jerarquía, tipografía, espaciado y acabado. Conserva la identidad de Arca Nova y toma el logotipo oficial de `web/public/brand/arca-nova-logo.png`.
- Consulta `design-taste-frontend` (Taste Skill) al definir una dirección visual, seleccionar referencias o rediseñar una pantalla. Usa las referencias compatibles con la identidad del producto y respeta los patrones existentes del proyecto.
- Consulta `emil-design-eng` y la skill de animación correspondiente cuando cambies una transición, un gesto o una microinteracción. Para revisar animaciones existentes, usa `review-animations`. Respeta la preferencia de movimiento reducido.
- Si la tarea incluye un archivo o enlace de Figma, consulta el diseño con Figma MCP antes de implementarlo.
- Al completar un cambio visual, abre la aplicación local con Playwright, recorre el flujo afectado y revisa la vista de escritorio y la móvil cuando corresponda. Si Playwright MCP no está disponible, usa la herramienta de navegador disponible e indica qué comprobaste.
